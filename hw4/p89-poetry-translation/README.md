# P89：唐诗宋词英译提示对照实验

状态：工作区已建立，实验尚未开展。

## 题目要求

依据 `L3-part1.pptx` 实际第 89 页及第 86–88、90–93 页上下文：自选一批唐诗宋词，在相同模型与配置下，比较直接翻译、加入任务标准、只加入边界示例等提示版本，检验参考资料和示例的实际作用。

先明确受众、翻译目的和允许的改写程度，再评价关键含义、意象、情感与英语表达。保留每个版本的原始输出，记录改对、新增错误与成本。方案锁定后，用未参与调试的材料独立检验，允许最简提示胜出。

不能调用模型时，可先练习盲评和错误定位；该结果属于评分流程练习，需要与模型实测分开记录。

## 目录约定

| 目录 | 后续用途 |
| --- | --- |
| `data/` | 原诗、出处、任务说明与开发／独立测试划分 |
| `prompts/` | 基线、任务标准、参考资料与边界示例版本 |
| `results/` | 原始输出、运行配置、评分与成本记录 |
| `reports/` | 实验分析、对照表与最终报告 |

共享课件位于 `../materials/`。本目录与第一题的研究数据、脚本和结果分别保存。
