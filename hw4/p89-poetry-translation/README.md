# P89：唐诗宋词英译提示对照实验

状态：已完成。最终报告见 [研究报告_唐诗宋词英译提示对照.md](reports/研究报告_唐诗宋词英译提示对照.md)。

## 结论摘要

- 默认保留 **V0（最简提示）**：独立测试集术语归一化分 1.00、关系 0.96（按原细则统一歧义口径后关系同为 1.00）、无重大错误、成本最低。
- 唯一值得条件性保留的改动：对确有生僻专名或关键歧义的诗句按需附加 **单条简短中性注释（A1）**。阶段 II 新增 24 次单条注释消融实验（D02/D09 诊断诗 + N01《商山早行》/N02《竹里馆》新增诗）表明，A0（无注）、A1（单条注）、A2（完整注）术语与关系均达 1.00，但 A2 导致 100% 尾注膨胀（平均 3.88 行/首，总 Token 达 1.56×），而 A1 将尾注控制在 1.00 行且在新增专名诗上节省推理成本。
- V1 任务标准：开发集关系/术语有提升，但引发诗行散文化（英语表达 1.625/2），且总 Token 增至 2.49×（其中 96.4% 的输出为内部思维链推理），适合作为事后评估标尺而非生成提示。
- V2 参考注释：开发集字面术语分 0.97，但测试集术语与 V0 同为 1.00；多词条注释易造成字面捆绑与尾注复述。
- V3 边界示例：仅对同类句式有效，迁移有限（T08 漏译“亭”），不作为默认保留。

## 题目要求

依据 `L3-part1.pptx` 实际第 89 页及第 86–88、90–93 页上下文：自选一批唐诗宋词，在相同模型与配置下，比较直接翻译、加入任务标准、只加入边界示例等提示版本，检验参考资料和示例的实际作用。

先明确受众、翻译目的和允许的改写程度，再评价关键含义、意象、情感与英语表达。保留每个版本的原始输出，记录改对、新增错误与成本。方案锁定后，用未参与调试的材料独立检验，允许最简提示胜出。

不能调用模型时，可先练习盲评和错误定位；该结果属于评分流程练习，需要与模型实测分开记录。
