## 2. 任务界定：受众、目的与改写自由度

### 2.1 主任务与第二评价标准

用户已确认“两种目的都做”。本设计把它落实为**同一批输出、两套盲评标准**，不另跑一套自由改写的提示：

- **S_F（主标准）忠实文学译介**：受众为英语一般读者，不懂中文，在诗选中初次接触中国古典诗词；目的是忠实文学译介，不是学术注疏。允许为英语语法调整语序、跨行组织；可为文化专名加最多两条简短尾注；不允许增删原诗意象、把含蓄处改成明说、改写成散文或英语创作、加入原诗没有的典故或解释性正文。
- **S_R（第二标准）自由改写/再创作视角**：把同一输出当作“受原诗启发的英语诗”来评，允许重组、增删意象、改变行序；不惩罚有意的改写，但要求核心情感/思想仍可辨认、没有因误读造成的意义反转、作为英语诗成立。输出本身没有被要求标注“改编”，因此 S_R 不评“改编标注”，只评诗的效果与误读边界。

理由：第 87 页明确建议“先按忠实译介、再按自由改写分别盲评，观察排序是否变化”。用同一批输出换标准，可以直接回答“偏好是否随目的改变”，而不把“提示里写哪种目的”与“评分标准”混在一起。局限是：本轮没有专门要求自由改写的提示版本，S_R 是对同一输出的反事实用途评价；若后续要测“在提示中明确要求改写”的效果，可另加 V1-R 变体。

输出契约（所有版本相同）：只给译文；如需尾注，放在译文后的 `Notes` 小节；不要解释翻译选择。

### 2.2 评价维度

按第 86、88 页的要求拆开，不合成一个“文学性”总分。下表是 S_F（忠实译介）的维度；S_R（自由改写视角）的维度见 §7.4：

| 维度 | 看什么 |
| --- | --- |
| 关键含义 | 漏译、增译、误译、否定/条件辖域错误 |
| 术语与文化词 | 专名、物象词、典故的处理：正确且可懂 / 可接受 / 错误 / 省略 |
| 关系保持 | 拟人方向、对仗与对照、否定辖域、假设与时间跳转、因果与目的、意象并置、反问 |
| 意象 | 核心物象是否保留；替换是否改变原意 |
| 情感与语气 | 含蓄/直露程度、悲凉/旷达等基调是否偏移 |
| 英语表达 | 语法、自然度、文学语域；不要求押韵 |
| 格式 | 只给译文、行序、注释位置、是否添加解释性正文 |

## 3. 规则翻译的检查项怎样迁移到诗词

第 89 页“期限、否定、例外、术语与格式”沿用了前面规则翻译案例的检查项。直接套到诗词会失真，本设计按下表迁移，并在报告中说明理由：

| 原检查项 | 诗词中的处理 |
| --- | --- |
| 期限 | 诗歌没有“交付期限”。若原诗含明确时间终点（如“到天明”“何时了”），归入“时间关系”，不单列期限错误 |
| 否定 | 保留为独立项：否定辖域、双重否定、反问（何须、岂在、安得） |
| 例外 | 迁移为条件、假设、让步、唯一性（若是、何当、唯有、只是、却） |
| 术语 | 迁移为文化专名、物象词、典故与固定表达 |
| 格式 | 保留：译文/注释分离、行序、不添加解释性正文 |

## 5. 四个提示版本

### 5.1 共同底座（所有版本逐字相同）

```text
Translate the following Chinese poem into English.

Output: the English translation. If you add endnotes for culture-specific
terms, place them after the translation under a short "Notes" heading.
Do not add any other commentary.

Title: {title}
Author: {author} ({dynasty})

{text}
```

底座只规定输出契约，不提供任何内容提示，保证四版的格式要求可比。

### 5.2 V0：直接翻译

底座 + 原诗，不加任何说明。对应“最简单提示”。

### 5.3 V1：加入任务标准

底座 + 以下任务标准（对所有诗相同）：

```text
Audience: general English-language readers with no Chinese, encountering
classical Chinese poetry in an anthology.
Purpose: faithful literary translation, not adaptation.

Requirements:
1. Preserve the sense and sequence of every line; do not merge, omit, or add lines.
2. Preserve the key images and the relations between them: who acts on whom
   (including personification), contrasts and antitheses, the scope of negations,
   and hypothetical or temporal shifts.
3. Render culture-specific terms so that an English reader can understand them.
   Keep the original image rather than substituting a different one. Use a brief
   endnote if necessary.
4. Do not import images, allusions, or explanations not present in the source;
   do not paraphrase the poem into prose.
5. Use natural contemporary literary English; line breaks should follow the
   source; rhyme is not required.
6. Keep the emotional stance and degree of explicitness; do not make the poem
   more sentimental or more explicit than the original.
```

### 5.4 V2：只加参考资料

底座 + 该首诗的参考注释（2–4 条英文词条，解释文化词、地名、典故，不给整句译文）+ 原诗。示例：

```text
Reference notes for this poem:
- 鹿柴 (Lùzhài): a place name; literally "deer enclosure".
- 返景: evening sunlight reflected back into the forest.
- 苔: moss.
```

参考注释在运行前一次性写好，测试集的注释也在看到任何模型输出之前完成。

### 5.5 V3：只加边界示例

底座 + 4 组示例（来自不参与评分的诗）+ 原诗。示例只给“中文—英文”对，不写抽象规则；每组针对一类边界：

| 示例来源 | 边界现象 |
| --- | --- |
| 李白《月下独酌》“举杯邀明月，对影成三人” | 拟人方向：诗人邀月，影加入，三者关系不能反 |
| 杜甫《登高》“无边落木萧萧下，不尽长江滚滚来” | 否定性限定（无边/不尽）的辖域，不能译成“没有树/没有江” |
| 杜甫《茅屋为秋风所破歌》“安得广厦千万间，大庇天下寒士俱欢颜” | 假设/愿望（安得），不是已发生 |
| 李白《子夜吴歌·秋歌》“长安一片月，万户捣衣声” | 地名与文化动作（捣衣）的处理 |

示例译文为自拟，待阶段1定稿；不使用测试集 4 首中的任何句子，避免直接泄漏答案。

### 5.6 假设

| 编号 | 假设 | 预期可观察结果 | 若被推翻 |
| --- | --- | --- | --- |
| H1 | 任务标准减少关系错误（拟人方向、否定辖域、假设/时间跳转） | V1 的关系保持率高于 V0，尤其难句 | 两版无差异，说明模型已会或标准写得太抽象 |
| H2 | 参考资料减少术语错误，但不必然改善关系 | V2 术语分高于 V0，关系分接近 V0 | 术语仍错，说明注释没被使用或被过度解释 |
| H3 | 边界示例主要帮助与示例同类的现象，迁移到未见组合有限 | V3 在“拟人/否定/假设/术语”中的部分项改善，未覆盖项不改善 | 全面改善，说明示例起到了通用标准的作用，需检查是否被当成规则 |
| H4 | 对容易的诗，四版差异很小；收益集中在难项 | 分层报告：易项 ceiling，难项才有差异 | 易项也大幅波动，需检查评分敏感度或采样噪声 |

## 6. 运行与评价流程

### 6.1 固定配置

- 模型：`deepseek-v4.1-flash-1017`（同一实验只用一个模型）。
- 温度：0.2；`max_tokens`：12000；其余采样参数用网关默认。pilot 发现 V1 在 2000 token 时推理占满、正文为空；8000 可用，最终统一取 12000，四版相同。
- 每个“诗 × 版本”主实验 1 次；另取 3 首（易/中/难）做 2 次重复（每格共 3 次），检查稳定性。
- 调用顺序随机化，记录每次的 prompt tokens、completion tokens、延迟、返回模型名与重试次数。
- 原始响应逐条写入 JSONL，不删失败记录；失败重试单独计成本。

### 6.2 阶段

1. **试跑（pilot）**：1 首 × 4 版，检查输出解析、`reasoning_content` 是否占满 token、注释格式。
2. **开发集主实验**：8 首 × 4 版 = 32 次；加 3 首 × 4 版 × 2 次重复 = 24 次。
3. **盲评与统计**：去掉版本标签、随机编号；按 S_F 与 S_R 两套标准分别评；25% 样本二次盲评查一致性。
4. **锁定候选**：按预注册规则在开发集选一个版本（允许 V0 胜出）。
5. **测试集**：4 首 × 2 版（V0 与候选）× 2 次 = 16 次；只用于最终检验，不回头改提示。
6. **报告**：改对、新增错误、净变化、成本、失败与无法判定项全部保留。

### 6.3 盲评

- 输出去掉版本名，改为随机 ID；评分时不知道版本。
- 分两轮：先按 S_F 评“关键含义/术语/关系/意象/情感/英语/格式”，再按 S_R 评“核心情感可辨认/意象再创作/英语诗效果/误读边界”。两轮各自独立洗牌，避免第一轮的标准锚定第二轮。
- 先评可对照原文的项，再评英语表达与情感，减少风格偏好先入为主。
- 25% 样本在每轮评完后重新洗牌再评一次，报告一致率；若一致性低，先修订评分细则再继续。

### 6.4 统计

- 以“诗”为配对单位，报告每首每版的逐项分数与错误清单。
- 主要看配对差值的方向与幅度；用 bootstrap（重采样诗）给 95% 区间；样本小，不把 p 值当强结论。
- 同时报告“改对/新增/未变”的题数，不只报平均分。
- 分层看：易项/难项、唐/宋、术语/关系。

### 6.5 预注册的决策规则

锁定候选时，按以下顺序：

1. **主指标**：测试集上“关系保持率 + 术语正确率”是否高于 V0。
2. **护栏**：关键含义的重大错误不得比 V0 多；格式不得退化。
3. **成本**：token 与延迟增幅不超过 50%，除非主指标有稳定且明显的收益。
4. **最简胜出**：若候选与 V0 无实质差异，或收益只出现在个别样本，保留 V0。

## 7. 评分表与指标

### 7.1 逐项评分

| 项目 | 单位 | 记法 |
| --- | --- | --- |
| 关键含义 | 每首 | 重大错误数、次要错误数；错误类型：漏、增、误、辖域 |
| 术语 | 每个术语 | 0 错/漏；1 可接受但不充分；2 正确且可懂 |
| 关系 | 每条关系 | 0 丢失或反向；1 削弱；2 保持 |
| 意象 | 每个核心意象 | 0 替换/丢失；1 弱化；2 保留 |
| 情感/语气 | 每首 | 0 明显偏移；1 轻微；2 保持 |
| 英语表达 | 每首 | 0 影响理解；1 可读但不自然；2 自然且合语域 |
| 格式 | 每首 | 通过/不通过（译文与注释分离、行序、无额外解释） |

### 7.2 汇总指标

- 术语正确率 = 术语得分和 / (2 × 术语数)。
- 关系保持率 = 关系得分和 / (2 × 关系数)。
- 重大/次要含义错误总数。
- 增译与过度解释计数。
- 成本：输入/输出 token、总 token、延迟、重试次数、输出长度。

### 7.3 “改对/新增错误”的定义

- **改对（fixed）**：V0 中存在的重大错误或关系/术语失分，在候选版中不再出现。
- **新增错误（new）**：V0 中没有、候选版中新出现的重大错误或失分。
- **净变化** = 改对数 − 新增错误数；同时给出逐首清单，避免平均值掩盖反转。

### 7.4 S_R（自由改写视角）的评分

S_R 不惩罚有意的重组、增删意象或改变行序；它评的是“同一输出若用于自由改写任务，是否成立”：

| 项目 | 单位 | 记法 |
| --- | --- | --- |
| 核心情感/思想 | 每首 | 0 不可辨认或反转；1 部分可辨；2 清楚可辨 |
| 意象再创作 | 每首 | 0 意象混乱/丢失；1 有保留但弱；2 有效再创作 |
| 英语诗效果 | 每首 | 0 不成诗/难读；1 可读但平；2 有节奏、措辞与整体效果 |
| 误读边界 | 每首 | 0 因误读造成意义反转；1 有歧义但可接受；2 无误读 |

S_R 汇总分 = 四项之和（0–8）。S_R 只用于看“换目的后版本排序是否变化”，不参与候选锁定；锁定仍按 S_F 与决策规则。

## 8. 结果解释与可推翻条件

- 若 V1 只减少术语错误、不减少关系错误：说明任务标准主要补了“词”，没补“关系”，需要改写标准或承认模型的关系能力瓶颈。
- 若 V3 只在示例同类句子上有效：支持“示例是局部模式提示”，与第 90 页的提醒一致；测试集要包含示例未覆盖的组合。
- 若 V2 反而增加过度解释：参考资料提供了内容，但模型把注释扩张成正文；这本身是“参考资料的实际作用”的负面证据。
- 若四版差异很小：先检查是否样本太易、评分不敏感或模型已具备该能力，再决定是否继续加提示；不能为了正结果反复换种子。
- 若候选在测试集改对少、新增多：按规则保留 V0，并报告“没有发现值得保留的改动”。
- 若 S_F 与 S_R 的版本排序不同：说明“最好”依赖用途；报告哪些版本在忠实标准下更稳、哪些在自由改写视角下更有诗味，不把其中一个排序宣布为唯一正确。

## 9. 风险与局限

1. **单模型、小样本**：结论只适用于该模型与该批材料，不外推为“诗词翻译的普遍规律”。
2. **预训练污染**：这些名篇可能有公开英译，模型可能记忆；报告把它列为无法完全排除的混淆，不声称输出一定来自提示。
3. **评分者偏差**：主评分由我完成，二次盲评只能查一致性，不能替代独立人工评审；报告评分者身份与局限。
4. **网关注入**：第 15 页研究已观察到网关可能在开发者提示前注入平台规则；本实验记录每次 `prompt_tokens`，若发现异常注入，在报告中说明。
5. **示例复制**：V3 可能直接套用示例句式；用最长公共子串/短语重合检查，作为“新增错误/模板化”的证据之一。
6. **注释混淆**：V1 允许尾注、V2 提供参考注释、V3 示例含注释，术语可懂度会受注释影响；评分把“正文处理”和“注释处理”分开记。
7. **接口不稳定**：返回空内容、截断、超时都保留原样；重试成本计入。
