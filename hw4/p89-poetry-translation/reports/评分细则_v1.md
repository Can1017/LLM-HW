# 评分细则 v1（S_F 忠实译介 / S_R 自由改写视角）

> 适用：P89 实验的 V0–V3 输出；评分时不知道版本。
> 配套材料：`data/poems.json`、`prompts/`、`reports/阶段0_题目理解与实验设计_草案.md`。
> 本细则在运行计分实验前定稿；若 pilot 发现不可操作之处，先改细则并记录，再进入主实验。
>
> **v1.1（主实验后、评分前修订）**：
> 1. 题名专属词（T01 鹿柴、T02 鹳雀楼）不列入正文术语评分——共同输出契约要求不重复标题，正文没有这些词，按正文扣分会系统性误伤所有版本。
> 2. 格式按**共同输出契约**统一评：只要求译文完整、注释在 `Notes` 小节、无额外解释、行序一致；允许为英语语法跨行或合并相邻短句。V1 的“不合并行”是版本特有指令，盲评时不知道版本，因此改为锁定后的辅助核查，不进入主格式分。

## 1. 评分单位与文件

- 评分单位：一首诗 × 一个版本 × 一次生成的一条输出。
- 每条输出先按 **S_F（忠实文学译介）** 评，再按 **S_R（自由改写视角）** 评。
- 评分表以 CSV 保存；术语与关系按 `data/poems.json` 中的 ID 逐项记分，不临时增删锚点。
- 原文、术语表、关系表在评分时可见；版本名与调用参数不可见。

## 2. S_F：忠实文学译介

受众：英语一般读者，不懂中文，在诗选中初次接触中国古典诗词。
目的：忠实文学译介；允许为英语语法调整语序、跨行；允许简短尾注；不允许增删原诗意象、把含蓄处改成明说、改写成散文或英语创作、加入原诗没有的典故或解释性正文。

### 2.1 关键含义错误

以“读者是否会因此误解原诗”为标准，分两级：

| 级别 | 定义 | 例 |
| --- | --- | --- |
| 重大（major） | 意义反转、核心关系丢失、整行漏译、增加改变原意的意象/情节 | 把“不见人”译成“山里没有人”；把“何当”译成已发生的团聚；把“两情若是久长时”译成“爱情长久”而丢掉条件 |
| 次要（minor） | 细微削弱、词义不精确、局部语气偏移，不改变核心意义 | “青苔”译成“mossy ground”；“晚风”译成“night wind”但方向仍对 |

错误类型记在备注里：漏译（omission）、增译（addition）、误译（mistranslation）、辖域/方向错误（scope/direction）。

### 2.2 术语（每个术语 0–2）

术语锚点见 `data/poems.json` 的 `terms`。评分时把“正文处理 + 尾注”合起来看是否能让目标读者理解，但另记处理方式（正文/注释/省略）。

| 分 | 标准 | 例（T01 鹿柴） |
| --- | --- | --- |
| 2 | 正确且语境中可懂；专名可音译但保留“地名/建筑”的性质 | “Deer Enclosure”并让读者知道是地名；或音译 + 注释 |
| 1 | 部分正确、字面但不够可懂，或只在注释中含糊带过 | “deer fence”但未说明是地名；红豆只译“red beans”而未传达相思信物 |
| 0 | 错误、替换成不同事物、或完全省略 | “deer firewood”；把“寒山寺”译成“Cold Mountain Temple”却不表明是寺名；漏掉“返景” |

题名专属词（T01 鹿柴、T02 鹳雀楼）不计入正文术语分：输出契约要求不重复标题，正文没有这些词；V2 的参考注释仍可提供背景。计分时只使用 `TITLE_ONLY_TERMS` 之外的术语 ID。

### 2.3 关系（每条关系 0–2）

关系锚点见 `data/poems.json` 的 `relations`。关系是本次实验的主指标，必须逐条评。

| 分 | 标准 | 例（T01-R1 否定/听觉） |
| --- | --- | --- |
| 2 | 方向、辖域、对照、条件、时间层次保持 | “No one is seen in the empty mountains, / yet voices are heard.” |
| 1 | 削弱或含糊，但没有反转 | “No one is in the empty mountains, / but human voices sound.”（仍保留声音，但“没有人”偏强） |
| 0 | 丢失或反转 | “There is no one in the empty mountains.”（丢掉“但闻人语响”的转折） |

其他锚点的判定要点：

- **拟人方向**：谁对谁做动作不能反。T05“愿君多采撷”是希望对方采，不是自己采。
- **否定辖域**：T03“绝/灭”是“完全消失”，不是“从未存在”；T10“不觉晓”是“没察觉天亮”，不是“天没亮”。
- **假设/条件**：T04“何当”、T06“我欲…又恐”、T12“若是”都不能译成事实。
- **时间层次**：T04 现在→未来→未来回忆现在，压成一层记 0 或 1。
- **反问**：T07“怎敌他”、T08“几时回”、T11“问君能有几多愁”、T12“岂在”是反问/设问，不是普通提问。
- **歧义**：T09“对愁眠”、T11“朱颜改”允许两种合理解读；只要译文内部一致、不把歧义说成确定事实，可给 2，并在备注记下所选解读。

### 2.4 意象（每首 0–2，按 `key_images` 集合整体评）

| 分 | 标准 |
| --- | --- |
| 2 | 核心意象都在，且在原诗的关系中起作用 |
| 1 | 个别意象弱化或被近义替换，整体画面仍成立 |
| 0 | 关键意象丢失/替换成不同事物，画面或意义受损 |

逐项丢失的意象写在备注里，不另设分值。

### 2.5 情感/语气（每首 0–2）

| 分 | 标准 |
| --- | --- |
| 2 | 与原诗的含蓄/直露程度、悲凉/旷达等基调一致 |
| 1 | 轻微偏移（略更伤感、略更平淡），不影响整体 |
| 0 | 明显偏移（把含蓄改成煽情、把悲凉改成欢快、把反问改成说教） |

### 2.6 英语表达（每首 0–2）

| 分 | 标准 |
| --- | --- |
| 2 | 语法正确、自然、合文学语域；行文可朗读 |
| 1 | 可读但生硬、搭配不自然、语域混杂 |
| 0 | 语法/用词错误影响理解，或明显机器式堆砌 |

不要求押韵；不因“没有押韵”扣分。

### 2.7 格式（通过/不通过）

同时满足以下条件为通过：

1. 有完整译文；
2. 如有注释，注释在译文后单独的 `Notes` 小节；
3. 没有“Here is a translation”“I chose…”等额外解释，也没有重复标题/作者；
4. 行序与原诗一致；允许为英语语法跨行，或把相邻短句并成一行，只要顺序不变。V1 的“不合并行”不进入主格式分，锁定后作辅助核查。

不通过时记录具体原因。格式按共同输出契约统一评，不按版本特有指令评。

## 3. S_R：自由改写视角

S_R 不惩罚有意的重组、增删意象、改变行序；它评“同一输出若用于自由改写任务，是否成立”。四项各 0–2，合计 0–8。

| 项目 | 0 | 1 | 2 |
| --- | --- | --- | --- |
| 核心情感/思想 | 不可辨认或反转 | 部分可辨 | 清楚可辨 |
| 意象再创作 | 意象混乱/丢失 | 有保留但弱 | 有效再创作 |
| 英语诗效果 | 不成诗/难读 | 可读但平 | 有节奏、措辞与整体效果 |
| 误读边界 | 因误读造成意义反转 | 有歧义但可接受 | 无误读 |

注意：S_R 是对同一输出的“反事实用途”评价，不是一次自由改写实验；报告时不能写成“模型在自由改写任务上的表现”。

## 4. 评分流程与盲评

1. 运行结束后，`harness/make_blind_packet.py` 去掉版本名，生成随机 `blind_id`；密钥表单独保存。
2. 第一轮按 S_F 评：先读原文与术语/关系表，再读译文；先评含义/术语/关系，再评意象/情感/英语/格式。
3. 第二轮重新洗牌，按 S_R 评；不要回看第一轮的版本猜测。
4. 每轮抽 25% 输出，在全部评完后重新洗牌再评一次；报告：
   - 重大错误数的完全一致率；
   - 关系分的完全一致率与“相差 ≤1”的比例；
   - 不一致处的具体片段。
5. 若一致率低于 80%，先修订细则并说明，再继续；不把修订前的分数混入最终结果。

## 5. 汇总与“改对/新增错误”

每条输出记录：

- `term_scores`：`T01-T1:2;T01-T2:1;...`
- `relation_scores`：`T01-R1:2;...`
- `major_errors`、`minor_errors`：数量；`error_log`：逐条描述。
- `image_score`、`emotion_score`、`english_score`、`format_pass`（1/0）。
- `s_r_core`、`s_r_imagery`、`s_r_poem`、`s_r_misread`。

汇总：

- 术语正确率 = 术语分和 / (2 × 术语数)。
- 关系保持率 = 关系分和 / (2 × 关系数)。
- 重大/次要错误总数；增译/过度解释计数。
- S_R 总分 = 四项之和。

“改对/新增”按误差单位比较同一首诗的 V0 与候选版：

- **改对（fixed）**：V0 中为 0 分的关系/术语，在候选版变为 1 或 2；或 V0 的重大错误在候选版消失。
- **新增错误（new）**：V0 中为 2 分的关系/术语，在候选版降为 0/1；或候选版出现 V0 没有的重大错误。
- **净变化** = 改对数 − 新增错误数；逐首列出，不只报平均。

## 6. 候选锁定规则（预注册）

按顺序比较：

1. **主指标**：测试集关系保持率；同时看“关系 0 分”的条数。
2. **次指标**：术语正确率；“术语 0 分”的条数。
3. **护栏**：重大含义错误不得多于 V0；格式不得退化。
4. **成本**：token 与延迟增幅不超过 50%，除非主指标有稳定且明显的收益。
5. **最简胜出**：若候选与 V0 无实质差异，或收益只出现在个别样本，保留 V0。

S_R 只用于二次分析：看换目的后版本排序是否变化；不参与锁定。

## 7. CSV 字段

| 字段 | 说明 |
| --- | --- |
| `blind_id` | 盲评编号 |
| `poem_id` | 诗 ID |
| `term_scores` | 术语逐项分，`ID:score` 分号分隔 |
| `relation_scores` | 关系逐项分，`ID:score` 分号分隔 |
| `major_errors` / `minor_errors` | 数量 |
| `error_log` | 逐条错误：级别、类型、片段、理由 |
| `image_score` / `emotion_score` / `english_score` | 0–2 |
| `format_pass` | 1/0 |
| `s_r_core` / `s_r_imagery` / `s_r_poem` / `s_r_misread` | 0–2 |
| `notes` | 歧义解读、注释使用、无法判定项 |

## 8. 评分者声明

主评分由本会话的 AI 助手完成；二次盲评用于查一致性，不等同于独立人工评审。报告会写明这一点，不把 AI 评分说成人类专家评分。遇到无法判定的项，保留 `unclear` 并说明原因，不强行给分。
