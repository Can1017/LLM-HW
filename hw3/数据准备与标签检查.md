# HW3：数据准备与标签检查

## 1. 数据来源与清洗

本实验直接读取课程提供的人民日报半年带音压缩包，输入 SHA-256 为 `30c4435bcce7d082c2175720a4549114f80656761df95d3c8b20f0ee48e5d7ab`。六个月共有 18,631 个原始文章编号，清洗后按无标点正文指纹去除 49 篇重复文章。五个异常编码段落已隔离，原字节、段落编号和错误位置保存在 `data/quarantine.json`。处理前后压缩包字节指纹一致。

八类标签包括无标点及 `，。？！、：；`。清洗移除注音、分词空格和文章编号，保留正文、数字及字母；全角数字转换为半角。引号、括号和书名号按照本次标签范围移除。省略号、破折号和一个位置对应多个主标点的歧义标签使用忽略值，并在统计文件中单列计数。

## 4. 古文外部评测集

采用 [CCLUE](https://github.com/Ethan-yt/CCLUE) 固定提交 `ed481c453c1c36397f86905a2bda625ecc5607e1` 的标点开发集与测试集。实际有效样本分别为 4,074 条和 3,992 条；开发集比上游 README 的 4,075 条少一条，实验以实际读取的有效记录计数。

发布者对底层古籍做过简体转换、符号清理、书籍筛选及段落抽样。HW3 使用其已发布的 `punc_tags` 作为古文迁移评价标签，记录数据文件指纹和处理来源。当前阶段使用新闻语料训练，古文开发集用于了解迁移行为，测试集用于最终外部评价。
