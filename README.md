获取完整代码及 KenLM 子模块：

```bash
git clone --recurse-submodules https://github.com/Can1017/LLM-HW.git
cd LLM-HW
```

运行 HW1 时进入 `hw1/`，运行 HW2 时进入 `hw2/`，再按对应 README 配置环境与数据。实验报告中的项目链接指向 GitHub，图片使用完整在线地址，单独保存报告后仍可通过网络访问。
